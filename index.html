RAG-Based Search Platform

Scalable Retrieval-Augmented Generation search over XML, PDF & PPTX documents. Elasticsearch + BERT + LLMs with real-time indexing.

Multi-modal chunker → BERT embeddings → Elasticsearch hybrid search → LLM re-ranker with citation-grounded answers.
